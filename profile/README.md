# HelloRIC
This is the Github Organisation for the HelloRIC Student Project from the [DFKI Robotics Innovation Center](https://robotik.dfki-bremen.de/) at [University Bremen](https://www.uni-bremen.de/).

More detail about the project itself can be found [here (in German)](https://robotik.dfki-bremen.de/en/teaching/student-projects/details/helloric)

You find documentation at: https://helloric.github.io/documentation/
